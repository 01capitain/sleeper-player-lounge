# Players Lounge handoff

Implementation-ready starter assets for a local fictional NFL-player group chat around the **hotelkit Fantasies** Sleeper slow draft.

Start with `implementation_plan.md`.

## Product rules already decided
- local-first / Git-friendly
- hotelkit Fantasies is the target 2026 pre-draft league
- simulate using another completed 2026 draft from Sleeper user `01capitain`
- drafted player always reacts
- relevant current NFL teammates are favored
- ~10–20 recurring star players
- required stars: Aaron Rodgers, Travis Kelce, Kyle Pitts
- normal fantasy memory: 2025 only
- older history: championship membership only
- historical dialogue must explicitly mention the season
- 2025 disappointments may hope for a better 2026
- PNG + GIF + MP4 rendering
- fictional Players Lounge UI, not an exact fake Sleeper screenshot

## Recommended next command for an implementation agent
Read `implementation_plan.md`, scaffold a Node/TypeScript CLI, then implement Milestone A end-to-end before expanding scope.
